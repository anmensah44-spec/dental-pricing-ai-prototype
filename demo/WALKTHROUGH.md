# Five-minute interviewer walkthrough

1. **0:00–0:40 — Frame the problem.** Explain coordinator/finance needs, owner contribution and AI-assisted implementation. State synthetic-only and no vendor relationship.
2. **0:40–1:40 — Price a crown.** Start the app, open pricing, use the sample crown at 75 minutes and $280 lab cost, approved plan, fresh benefits and no insurance. Inspect model estimate, interval, selected price and patient balance. Explain ±5% and margin controls.
3. **1:40–2:30 — Show financial boundaries.** Toggle insurance and observe fixed fictional contract and suppressed loyalty discount. Add a deposit and financing; verify fee uses remaining balance. This is an estimate, not a payer guarantee.
4. **2:30–3:20 — Show exception handling.** Remove approval or mark benefits stale. Show review routing. A filling with 110 minutes and zero lab cost demonstrates infeasibility without relaxing policy.
5. **3:20–4:10 — Show the journey.** Reopen an issued decision, accept before expiry, export JSON, submit simulated financing and select a simulated outcome. Explain browser storage and lack of real underwriting.
6. **4:10–5:00 — Show evidence.** Open evaluation.json, run npm test, show architecture and readiness gaps. Discuss what representative data and a shadow pilot would resolve.
